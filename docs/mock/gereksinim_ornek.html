Şartnamedeki "ne doğrulanacak" maddeleri stokta tek tabloda toplanır; her madde sonra test planına (TP) ve test raporuna (TR) bağlanır.
KAYNAKDOORS · TEST GEREKSİNİMİ DOKÜMANI
AB-7000-0002 Test Gereksinimleri · Rev AA
DGÖ-1 Anten 3 dB yanca hüzme genişliği 8–12 GHz bandında ≥ 30° olmalıdır.
DGÖ-2 Yan lob seviyesi ≤ −15 dB olmalıdır.
DGÖ-5 Anten −40…+71 °C'de çalışmalıdır.
Tasarımcının Word dokümanındaki numarasız madde: TG no yerine doküman no (ör. TSD-0042) yazılır, Tür = Türetilmiş, Bağlı = DGÖ-1.
